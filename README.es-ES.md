# Una Práctica Hoja de Referencia de Ncurses
Una práctica hoja de referencia para programadores que trabajan con la [biblioteca ncurses de GNU](https://www.gnu.org/software/ncurses/). Documentación resumida completa y detalles de uso. Este es un documento de referencia que le ayudará en el proceso de construir grandes proyectos interactivos de línea de comandos utilizando la biblioteca ncurses de GNU.
